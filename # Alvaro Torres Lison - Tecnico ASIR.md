#### Ejemplo de automatización (Bash)
Este bloque de código muestra un script básico que utilizo para verificar la conectividad de un servidor:

```bash
#!/bin/bash
# Comprobación de estado de servidor
SERVER="8.8.8.8"
if ping -c 1 $SERVER &> /dev/null
then
  echo "El servidor $SERVER está ONLINE"
else
  echo "ALERTA: El servidor $SERVER no responde"
fi
```
